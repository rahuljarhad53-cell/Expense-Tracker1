# 💰 Expense Tracker

## 📌 About the Project
Expense Tracker is a simple Python-based application that helps users manage their daily expenses by organizing them into different categories. Users can add expenses, create categories, and view the total amount spent in each category.

## ✨ Features
- ➕ Add new expenses
- 📂 Add expense categories
- 📊 View total expenses by category
- 📋 View expense categories
- 📅 Enter expense dates
- 💵 Track expense amounts
- 🚪 Simple menu-driven interface

## 🛠️ Technologies Used
- Python 3
- Python Dictionaries
- Object-Oriented Programming (OOP)
- Command-Line Interface (CLI)

## ⚙️ Installation and Setup

### 1. Install Python
Download Python from https://www.python.org/downloads/

### 2. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 3. Open the Project Folder

```bash
cd ExpenseTracker
```

### 4. Run the Application

```bash
python expense_tracker.py
```

## 🚀 How to Use

1. Run the Python program.
2. Select an option from the menu.
3. Choose **1** to add an expense.
4. Choose **2** to add a category.
5. Choose **3** to view expenses.
6. Choose **4** to view categories.
7. Choose **5** to exit the application.
